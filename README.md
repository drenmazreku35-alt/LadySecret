# LADY'S SECRET — Website Profesional

Butik luksoz online për Instagram @ladysecret_ks (Çanta & Këpucë, Prizren).

## Struktura (HTML + CSS + JS + JSON)
```
LadySecret Website/
  index.html          → struktura (HTML)
  css/style.css       → dizajni luksoz (CSS)
  js/app.js           → dyqani + shporta + admin (JavaScript)
  data/products.json  → backup i produkteve (JSON)
  manifest.json       → PWA / install si app (JSON)
  sw.js               → offline cache (JavaScript)
  robots.txt          → SEO
```

## Si hapet
1. Double-click `index.html`
2. Për admin (i fshehur — s'duket në faqe): shto `#admin` në fund të adresës
   (p.sh. `.../index.html#admin`), OSE kliko logon 5 herë shpejt, OSE shkruaj `lady` me tastierë → fjalëkalimi `drenidreni123`
3. Shto produkt: emër + çmim + foto (upload nga PC/telefon ose URL) → Publiko
